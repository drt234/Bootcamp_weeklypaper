# 피벗 테이블 vs SUMIF·COUNTIF

> **Q.** Excel로 데이터를 집계할 때, 피벗 테이블을 쓰는 방식과 SUMIF·COUNTIF 같은 수식으로 직접 계산하는 방식 중 어느 쪽이 더 좋다고 생각하나요? 선택한 이유와 함께 설명해 보세요.

- 작성일: 2026-11-23
- 키워드: `Excel` `집계` `피벗테이블`

---

## 💡 나의 답변

하나만 고르라면 **피벗 테이블**입니다. 다만 **처음 데이터를 탐색할 때는 피벗 테이블**, **고정된 보고서나 양식을 만들 때는 수식**처럼 상황에 따라 나눠 쓰는 게 가장 좋다고 생각합니다.

## 🔍 그렇게 생각한 이유

| 기준 | 피벗 테이블 | SUMIF·COUNTIF |
|------|-------------|---------------|
| 속도 | 드래그 몇 번으로 집계 | 조건마다 수식을 직접 작성 |
| 유연성 | 행/열 기준을 바로 바꿀 수 있음 | 기준을 바꾸려면 수식을 수정 |
| 원본 변경 시 | '새로 고침'을 눌러야 반영 | 즉시 자동 반영 |
| 다른 사람과 공유 | 구조가 직관적이라 이해하기 쉬움 | 원하는 양식에 맞춰 배치하기 좋지만, 수식을 읽어야 이해 가능 |

1. **관점을 빠르게 바꿔 볼 수 있습니다.** 분석 초반에는 "월별로 볼까, 지역별로 볼까?"처럼 기준을 계속 바꿔 봐야 하는데, 피벗 테이블은 이 과정을 몇 초 만에 해 줍니다.
2. **실수할 위험이 적습니다.** 수식은 참조 범위를 잘못 잡거나 조건에 오타가 나도 그럴듯한 숫자가 나와서 오류를 알아채기 어렵습니다. 피벗 테이블은 원본 범위만 맞으면 집계가 자동으로 정확하게 됩니다.
3. **수식이 나은 경우도 분명히 있습니다.** 매주 같은 양식으로 나가는 보고서, 다른 셀과 계산이 연결된 대시보드, 원본이 바뀌면 바로 반영돼야 하는 표에는 SUMIF(S)·COUNTIF(S)가 더 적합합니다.

## 📌 예시

지역별 매출 합계를 구하는 상황에서:

- **피벗 테이블:** 행에 `지역`, 값에 `매출(합계)`를 넣으면 끝입니다. 이어서 열에 `월`을 추가하면 지역×월 교차표가 바로 만들어집니다.
- **수식:** 보고서 양식의 정해진 칸에 숫자를 넣어야 할 때 사용합니다.

```
=SUMIF(B:B, "서울", D:D)               // 서울 지역 매출 합계
=COUNTIF(B:B, "서울")                   // 서울 지역 주문 건수
=SUMIFS(D:D, B:B, "서울", C:C, "1월")   // 서울 + 1월 매출 합계
```

## ✍️ 정리

탐색은 피벗 테이블로 빠르게, 정해진 양식의 보고서는 수식으로 정확하게.
