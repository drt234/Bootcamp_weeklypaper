# 결측값 처리, 무조건 제거하면 안 되는 이유

> **Q.** 실제 데이터를 다루다 보면 '결측값 처리'가 생각보다 까다롭습니다. 결측값을 무조건 제거하는 것이 왜 위험할 수 있는지, 그리고 본인이라면 어떤 기준으로 처리 방법을 결정하겠는지 설명해 보세요.

- 작성일: 2026-11-23
- 키워드: `전처리` `결측값` `pandas`

---

## 💡 나의 답변

결측값을 무조건 지우면 **데이터가 크게 줄고 결과가 한쪽으로 치우칠 수 있습니다.** 그래서 저는 먼저 **왜 비어 있는지**를 확인하고, **결측 비율과 변수의 성격**에 따라 제거·대체·별도 범주 중 하나를 고르겠습니다.

## 🔍 그렇게 생각한 이유

### 무조건 제거하면 위험한 이유

1. **데이터 손실:** 컬럼이 많으면 한 칸만 비어도 행 전체가 사라집니다. 결측이 여러 컬럼에 흩어져 있으면 전체 데이터의 절반 이상이 없어질 수도 있습니다.
2. **편향(bias) 발생:** 결측은 무작위가 아닌 경우가 많습니다. 설문에서 소득 항목을 비운 사람이 특정 소득층에 몰려 있다면, 그 행을 지운 뒤의 결과는 실제 모집단을 대표하지 못합니다.
3. **결측 자체가 정보일 수 있음:** 호텔 예약 데이터에서 '요청사항'이 비어 있다는 건 "요청이 없었다"는 뜻일 수 있습니다. 노쇼 고객일수록 특정 정보를 입력하지 않았다면, 결측 여부 자체가 의미 있는 특징이 됩니다.

### 내가 처리 방법을 정하는 기준

1. **결측이 생긴 이유:** 시스템 오류인지, 해당 사항이 없는 건지(예: 무자녀 고객의 자녀 수), 응답을 거부한 건지 확인합니다.
2. **결측 비율:**
   - 아주 적고(예: 5% 미만) 무작위로 보이면 → 제거해도 영향이 작음
   - 상당 부분 비어 있으면 → 대체를 고려
   - 대부분 비어 있으면 → 그 컬럼을 분석에서 빼는 것을 검토
3. **변수의 성격과 분석 목적:**
   - 수치형: 이상치가 있으면 평균보다 **중앙값**으로 대체
   - 범주형: 최빈값, 또는 `'미입력'`이라는 별도 범주
   - 시계열: 앞뒤 값으로 채우기(ffill/bfill)나 보간
   - '해당 없음'이 명확한 경우: 0 같은 의미 있는 값
4. **처리 전후 비교와 기록:** 분포나 주요 지표가 크게 달라지지 않았는지 확인하고, 어떤 기준으로 처리했는지 남겨 둡니다.

## 📌 예시

```python
import pandas as pd

# 결측값 확인
df.isnull().sum()                      # 컬럼별 결측 개수
df.isnull().mean().round(3) * 100      # 컬럼별 결측 비율(%)

# 1) 결측이 아주 적은 핵심 컬럼 → 해당 행만 제거
df = df.dropna(subset=["booking_date"])

# 2) 수치형 → 중앙값으로 대체
df["price"] = df["price"].fillna(df["price"].median())

# 3) 범주형 → '미입력' 범주로 따로 표시
df["special_request"] = df["special_request"].fillna("미입력")

# 4) 결측 여부 자체를 특징으로 남기기
df["is_phone_missing"] = df["phone"].isnull().astype(int)
```
