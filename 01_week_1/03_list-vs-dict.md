# 리스트(list)와 딕셔너리(dict)의 사용 상황

> **Q.** 리스트(list)와 딕셔너리(dict)는 어떤 상황에서 각각 사용하나요? 데이터 분석 업무를 예시로 들어 설명해 보세요.

- 작성일: 2026-11-23
- 키워드: `Python` `자료구조`

---

## 💡 나의 답변

데이터를 **순서(위치)로 찾으면 리스트**, **이름(키)으로 찾으면 딕셔너리**를 사용합니다. "몇 번째 값인지"가 중요한지, "무엇에 대한 값인지"가 중요한지가 기준입니다.

## 🔍 그렇게 생각한 이유

### 리스트(list)를 쓰는 상황

- 시계열처럼 **순서 자체가 의미 있는** 값을 저장할 때 (일별 매출, 월별 방문자 수)
- 같은 종류의 값을 나열하고 **반복문으로 하나씩 처리**할 때 (파일 목록, 분석할 컬럼 목록)
- 같은 값이 중복돼도 괜찮을 때

### 딕셔너리(dict)를 쓰는 상황

- 카테고리별 집계 결과처럼 **이름표(키)로 값을 바로 찾아야** 할 때
- 코드값을 의미 있는 이름으로 바꾸는 **매핑**이 필요할 때 (데이터 정제)
- JSON/API 응답처럼 **"키-값" 구조**의 데이터를 다룰 때

## 📌 예시

```python
# 리스트 예시 (예: 일별 매출)
daily_sales = [120, 135, 98, 150, 170]
avg = sum(daily_sales) / len(daily_sales)
print(daily_sales[0])                      # 첫째 날 매출

cols = ["order_date", "price", "quantity"]  # 분석할 컬럼 목록
df = df[cols]

# 딕셔너리 예시 (예: 고객 ID별 정보)
customers = {
    "C001": {"name": "김철수", "grade": "VIP"},
    "C002": {"name": "이영희", "grade": "일반"},
}
print(customers["C002"]["grade"])          # 위치를 몰라도 ID로 바로 조회

status_map = {"C": "취소", "N": "노쇼", "O": "정상"}
df["status"] = df["status_code"].map(status_map)   # 코드 → 이름 매핑

df = df.rename(columns={"amt": "amount"})  # 컬럼 이름 변경
```

실무에서는 둘을 섞어서 `[{"name": "A", "sales": 100}, {"name": "B", "sales": 80}]`처럼 "딕셔너리의 리스트"로 쓰는 경우가 많고, 이 구조는 `pd.DataFrame()`으로 바로 표로 바꿀 수 있습니다.

## ✍️ 정리

순서가 중요하면 리스트, 이름표가 중요하면 딕셔너리.
